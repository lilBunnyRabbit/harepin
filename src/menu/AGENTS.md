# menu/

Owner's taste, settled:

- Everything lives in the main menu: no side sheets, popovers or separate windows.
- Settings are rows, not cards. Spacing is generous: "optimize spacing" means more room, never tighter.
- No native scrollbars (`scrollbar-width: none`).
- The garage's 3D car never moves between garage sections.
- Theme tokens only; never colour-mix primary, secondary, accent or foreground with each other. Icons get a fixed box (`flex: none`).
- Check a visual change by screenshot at 1280x720 and 844x390, dark and light, before committing.
