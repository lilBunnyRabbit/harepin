# UX mockups (approved 2026-11-17)

The source of truth for the UI rebuild. The owner approved every screen in round 3 of the r5 mockups.

- `screens.js`: one function per screen, desktop and phone. Where a screen had variants, the picked one is the live one: back B, online A, results B, settings A, minimap A, speedometer A.
- `frames.css` / `page.css`: the spacing scale, the radii, the type scale and the surface ladder, in theme tokens.
- `app.js` / `body.html`: the review page shell only, not for the game.

Tweaks the owner asked for on top, plus the lead's calls: quest `2026-11-16-ui-redesign.md`, section "UX r5 v3: APPROVED".
The images and the font are not in the repo. To view the page, open the published mockup artifact, or rebuild it from the lead's scratchpad.
